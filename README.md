# Daramadsazan Project 03 — Online Store & Affiliate Commerce

Persian RTL MVP frontend for an online store and marketer partnership model.

## Current functionality
- Responsive sample product catalog
- Local referral-link prototype using partner IDs and product IDs
- Link copy action and browser-local referral counter
- Assistant interface placeholder

## Not yet implemented
- Server-side catalog, stock, cart, checkout, and order management
- Payment gateway and verified payment callbacks
- Server-side referral attribution and commission ledger
- Partner onboarding, fraud controls, payout reconciliation
- AI backend, customer accounts, seller portal, invoices, and tax workflows

All product names and prices are illustrative. Referral links are prototypes only; they do not track purchases or create payable commissions.

## Roadmap
1. Backend API and relational schema for products, variants, stock, orders, partners, clicks, conversions, commission entries, and payouts
2. Authentication, authorization, audit trails, and admin/seller/partner roles
3. Payment provider integration with signed webhook verification and idempotent order updates
4. Attribution rules, refunds/chargebacks, commission holds, and payout reconciliation
5. Subscription tiers, seller fees, and operational dashboards

Never place payment secrets, API tokens, or customer personal data in frontend code or Git.
